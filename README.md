# Theme System Documentation
This project uses a `palette` → `theme` → `adapter` pipeline.

- Palette defines colors and metadata
- Theme applies defaults and overrides
- Adapters convert the theme into editor-specific formats
- How to Create?
    - [Theme](https://github.com/madhanmaaz/herzha-theme/blob/main/docs/create-theme.md)
    - [Adapter](https://github.com/madhanmaaz/herzha-theme/blob/main/docs/create-adapter.md)
